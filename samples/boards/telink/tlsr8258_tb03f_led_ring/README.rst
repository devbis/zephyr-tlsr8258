TLSR8258 TB03F LED ring
#######################

Overview
********

This sample targets the ``tlsr8258_tb03f`` board and rotates the five onboard
LEDs once per second:

* PB4 yellow
* PB5 white
* PC2 red
* PC3 green
* PC4 blue

The sample enables the TLSR8258 RTT console and logs boot plus each active LED
change via ``printk()``.
